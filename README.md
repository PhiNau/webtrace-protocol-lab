# WEBTRACE – Das Protokoll-Labor

Interaktives Lernspiel zu Netztopologien, Client-Server-Strukturen, Website-Aufrufen, HTTP, HTTPS und POP3.

## Lernweg

1. Sternstruktur und Client-Server-Rollen unterscheiden
2. Einen Website-Aufruf vom URL-Eintrag bis zur Darstellung rekonstruieren
3. HTTP und HTTPS vergleichen sowie Zertifikat und Statuscode auswerten
4. Einen fertigen Python-POP3-Client analysieren und eine POP3-Sitzung durchführen
5. Einen kombinierten Störungsfall anhand mehrerer Protokollspuren erklären

Die TCP/IP-Schichten werden bewusst nur knapp wiederholt. Zur Vertiefung verweist das Projekt auf den Grundkurs in M.A.R.A. – Protocol Recovery.

## Technik

Die Anwendung besteht aus statischem HTML, CSS und JavaScript in `dist/`. Fortschritt wird ausschließlich im lokalen Speicher des Browsers abgelegt.
